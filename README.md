# 🌷 Python Turtle Flower

A cute interactive flower created using Python's Turtle graphics.

The flower is drawn completely with Python using mathematical curves, colors,
randomly positioned hearts, and text-based petals.

## ✨ Features

- 🌸 Procedurally generated flower
- 💗 Pink layered petals
- 🌿 Curved green stem and leaves
- 💕 Random floating hearts
- ✨ "my love" text inside the petals
- 🖥️ Interactive Turtle graphics window

## 🛠️ Technologies

- Python 3
- Turtle Graphics
- Math
- Random
